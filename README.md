# OUC xv6 Lab Kit

*A six-lab xv6-riscv learning path for OUC operating-systems coursework.*


[English](README.md) | [简体中文](README.zh-CN.md)

**Guide:** [Status](#project-status) · [Where to start](#where-to-start)


OUC xv6 Lab Kit is a learning repository for an operating-systems course. It organizes an xv6-riscv path into six labs, from setup through core kernel work and integrated reproduction.

The material is intended to help students follow the code and understand how an operating-system change moves through the project. The repository includes lab instructions, tests, reproduction notes and course materials.

## Project status

Course learning kit. Follow the pinned lab instructions and references because results can vary across environments and upstream revisions.

## Where to start

Begin with the instructions for the lab you are working on, then follow its referenced setup and validation steps. The main folders are:

- labs/ — lab material
- tests/ — checks used by the project
- reproducibility/ — reproduction notes and supporting files
- submissions/ and slides/ — course deliverables

This repository is a course learning kit. It does not claim that every environment or upstream xv6 revision behaves identically; use the pinned references and notes included with each lab.
