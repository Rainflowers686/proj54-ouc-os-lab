# OUC xv6 Lab Kit

*中国海洋大学操作系统课程的六个 xv6-riscv 实验。*


[English](README.md) | [简体中文](README.zh-CN.md)

**导航：**[状态](#项目状态) · [从哪里开始](#从哪里开始)


OUC xv6 Lab Kit 是操作系统课程的学习仓库，将 xv6-riscv 的学习过程组织成六个实验，从环境准备到内核核心内容和综合复现。

材料帮助学生跟随代码理解操作系统修改在项目中的完整路径。仓库包含实验说明、测试、复现记录和课程资料。

## 项目状态

课程学习资料。请按实验中固定的说明和引用操作，不同环境及上游版本的表现可能不同。

## 从哪里开始

先阅读当前实验对应的说明，再按其中引用的步骤准备环境和验证。主要目录包括：

- labs/：实验材料
- tests/：项目使用的检查
- reproducibility/：复现说明和支撑文件
- submissions/ 与 slides/：课程交付材料

这是课程学习包，不保证所有环境或上游 xv6 版本表现完全相同。请按每个实验附带的固定引用和说明操作。
